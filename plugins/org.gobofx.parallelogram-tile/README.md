# Parallelogram Tile

The picture repeated on a sheared grid: every tile is a parallelogram
leaning by the skew, and the picture inside leans with it, so the wall of
copies reads as italic. 1×1 with no skew is a no-op.

- **Columns / Rows** — how many copies across and down (1 to 12 each).
- **Skew** — the lean, in tile widths per tile height, -1 to 1; 1 is 45 degrees on square tiles.

## Use it when

- A dynamic, sporty or editorial grid: a wall of the same shot that leans
  into the motion.
- Backgrounds for lower thirds and sting cards where a straight tile grid
  looks too static.
- A striped or diagonal motif built from one graphic, with the skew set to
  match an existing diagonal in the design.

## Avoid when

- Faces and type in the tiles: the shear distorts them and reads as an
  error rather than a style.
- A straight grid is all that is needed: Tile, with its mirror and gap, is
  the cleaner tool.
- Small tiles at a high skew; the copies shred into slivers and the picture
  stops reading.
