# Vignette

Darken (or tint) the picture towards its edges.

- **Strength**, **Size** (clear radius), **Softness** (falloff width).
- **Roundness** — circular or following the frame's shape. **Center**.
- **Color** — the edge colour; black by default.

## Use it when

- Drawing the eye to the subject on a frame with a busy edge.
- Unifying shots from lenses with different fall-off, on the track.
- Adding weight to a flat, bright frame, lightly.

## Avoid when

- On every shot at the default **Strength**. That is the "video look"; if it
  must be everywhere, go to 0.2 and forget it.
- A bright subject near the edge. The vignette fights it.
- A tinted **Color** over skin, and any hard crop. For a crop, use Shape Mask
  or Widescreen.
