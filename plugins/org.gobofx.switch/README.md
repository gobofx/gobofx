# Switch

A push that waits, snaps across in a blink and settles. Motion blur follows
the speed, so the snap reads as a fast move rather than a jump; both ends
are sharp.

- **Direction** — the way the pair travels.
- **Snap** — 0 a smooth slide, 1 nearly all the travel in the middle frames.
- **Blur** — motion blur at full speed, 0 off.
- **Ease** — timing applied before the snap.

## Use it when

- Quick channel-change cuts: screens, feeds, split-screen hops.
- Rhythmic edits where the move must land on the beat, not drift across it.
- Replacing a plain Push that feels slow at the same duration.

## Avoid when

- Long transitions; a two-second wait before a snap feels like a freeze.
- Mellow material where Push or Slide's even motion is the right tempo.
- Fine text in frame, which smears during the snap.
