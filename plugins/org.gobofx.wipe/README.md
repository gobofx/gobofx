# Wipe

A straight edge sweeps across the frame, revealing `to`.

- **Direction** — which way the edge travels.
- **Softness** — width of the feathered edge.
- **Ease** — timing.
- **Wobble** (signal, cc 1) — bends the edge; feed it an audio follower.

## Use it when

- Period and comedy: 1970s space opera, serials, newsreels.
- A split-screen reveal, with a little **Softness**.
- A map or a graphic card arriving from one side.

## Avoid when

- Narrative drama. The edge is a hand moving across the frame; hard cut.
- Two moving shots. The edge and the motion fight.
- More than a few per project. The **Wobble** signal is for performed work;
  unmotivated, it reads as a fault.
