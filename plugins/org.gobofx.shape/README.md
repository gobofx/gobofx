# Shape

A rectangle, ellipse, regular polygon or star with a fill and a stroke, over a
transparent background. Edges are signed-distance based, so they stay crisp
at any size and **Roundness** rounds every corner.

- **Shape**, **Sides** (polygon and star points), **Inner Radius** (star).
- **Fill / Stroke / Background** — colours with alpha; **Stroke Width** in px.
- **Center**, **Size** (in frame heights), **Aspect**, **Rotation**.
