# Static

A TV channel change: snow and rolling scanlines swallow the cut, then clear
on `to`.

- **Width** — how much of the transition the static covers.
- **Density** — how fully the snow covers the picture at the peak.
- **Scanlines** — strength of the rolling line pattern; **Grain** — snow size.

## Use it when

- A channel-change gag, surveillance or found footage, a retro broadcast
  frame.
- A horror beat where the signal fails.
- Cuts between "channels" in a montage, with sound design to match.

## Avoid when

- Narrative outside those registers. Hard cut.
- Without the hiss. Static with no audio is half a transition.
- More than once per project. For a white hit, use Flash.
