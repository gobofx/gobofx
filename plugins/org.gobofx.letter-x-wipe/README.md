# Letter X Wipe

`to` spreads from both diagonals as a widening X until it fills the frame.

- **Invert** — the X closes in from the corners instead.
- **Softness** — feather of the edges; **Ease** — timing.

## Use it when

- Period and comedy cuts, where the X is a knowing wink.
- Graphic cuts on the beat in a promo, especially with an X-shaped mark.
- Closing in (**Invert**) on a final card or an end title.

## Avoid when

- Anything with a face at centre. The diagonals cross at the nose.
- Narrative. Hard cut.
- You need direction, not shape. Use Wipe.
