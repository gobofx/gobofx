# Pixellate

Average the picture into square blocks.

- **Size** — block size in pixels. **Center** — where the block grid is anchored.

## Use it when

- Anonymising a face or a plate, through a mask on a duplicated layer.
- A retro reveal into a game aesthetic; animate **Size** down to 1.
- A low-resolution "loading" beat in a tech piece.

## Avoid when

- A stylisation over an entire scene. It is a device, not a look.
- You want dots, not squares. Use Halftone.
- Small **Size** on moving footage. The blocks crawl and read as a codec
  fault.
