# Clone Spin

The frame splits into tiles; each tile spins in place, becoming a small copy
of the whole of `from` as it turns, then shrinks away to reveal `to`. The
tiles run as a diagonal wave, so the cut travels across the frame.

- **Grid** — tiles across (2–12); rows follow the frame's aspect.
- **Turns** — full rotations each tile makes before it is gone.
- **Stagger** — 0 every tile spins together, 1 a wave from the top-left corner.
- **Ease** — timing.

## Use it when

- Energetic montage, sports and gaming recaps that want a mechanical flourish.
- Title sequences and bumpers where the frame itself is the graphic.
- A beat-synced cut: set Turns to match the tempo of the music.

## Avoid when

- Anything that should feel like a cut and not an event; a dissolve is kinder.
- Slow, quiet material: the spin is loud and will dominate the moment.
- You only want the multiplication, not the motion: Clones does that quietly.
