# Contrast

Push every value away from a pivot grey, or pull it in, in linear light.
The pivot is the tone that stays put; everything brighter gets brighter
and everything darker gets darker. Amount 1 is neutral whatever the pivot;
it ships at 1.25 so the effect is visible when added.

- **Amount** — 0 collapses the picture to the pivot, 1 is neutral, 2
  doubles the distance from it.
- **Pivot** — the grey that does not move, on the display scale (0.5 is
  mid-grey, as a waveform shows it; 0.18 pivots on linear 18 % grey).

## Use it when

- A flat, log-looking or hazy shot needs its range opened up before any
  look goes on.
- The blacks are already right and you want more bite without moving them:
  drop the pivot towards the black level.
- A graphic or a screen capture reads soft against footage and needs a
  little more separation.

## Avoid when

- Highlights are near clipping: above 1 they clip first; lower the exposure
  on Color Adjustments before adding contrast.
- You want an S-curve or a filmic roll-off: this is a straight line through
  the pivot, so skies and skin flatten past about 1.5.
- A colour cast is the real problem: contrast makes a cast stronger, not
  weaker; fix it with Levels or Color Balance first.
