# Color Adjustments

The everyday grade in one effect, working in linear light. All defaults are
neutral, so adding it changes nothing until you move a control.

- **Exposure** — in stops. **Contrast** — around 18 % grey.
- **Saturation** — 0 is monochrome, 2 is doubled.
- **Temperature** — cool to warm; **Tint** — green to magenta.

## Looks

Eight presets ship with the plugin, each a starting point over the same five
controls: **Mono**, **Noir**, **Bleach Bypass**, **Warm Sun**, **Cool**,
**Chrome**, **Desert** and **Urban**. Pick one, then move a control; the
preset is the values, not a lock. Looks that need lifted blacks or a hue
shift (Faded Film, Cross Process, Vintage, Instant Camera, Soft Tonal,
Print Transfer) live on the LUT plugin.

## Use it when

- A shot needs a quick, honest correction: exposure, a little contrast, a
  touch of warmth.
- Several shots should match before any styling starts (apply it on the
  track, fix the odd clip on the clip).
- You want a look that stays editable, not baked into a table.

## Avoid when

- The grade needs per-channel curves, lifted blacks or split toning: use
  LUT, Levels or Color Balance.
- Skin is in frame and you are tempted past ±0.3 temperature: faces go
  orange or grey before anything else does.
