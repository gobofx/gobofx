# Kaleidoscope Tile

A wedge of the picture mirrored into a tiled plane: the frame is cut into
square tiles, each one a small kaleidoscope folded from a wedge of the
source around its centre, and the tiles meet their own reflections so the
pattern runs seamlessly to the edges. There is no neutral setting; it is
always a pattern.

- **Segments** — mirrored wedges in each tile (1 to 16); 6 and 8 give the classic snowflake, 1 a plain half-fold.
- **Size** — tile size as a fraction of the frame height (0.1 to 1); the wedge always reads the full source height, so smaller tiles mean more copies, not less picture.
- **Angle** — rotation of the source wedge in degrees; animate it and the pattern breathes.

## Use it when

- A background, a bumper or a title bed should be built from the shot's own
  colours as a repeating ornament.
- A psychedelic or dream sequence wants wallpaper that still carries the
  scene's palette and motion.
- Fabric, tile and wrapping-paper mock-ups from a single texture clip.

## Avoid when

- A single large kaleidoscope around one point is wanted: that is
  Kaleidoscope, which also takes a performer's signals.
- The source has a clear subject that should stay recognisable; only a
  wedge around the frame centre survives, folded.
- Any naturalistic cut; this is a pattern generator wearing the footage.
