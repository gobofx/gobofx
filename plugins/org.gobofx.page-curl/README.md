# Page Curl

`from` peels away from a corner like a page turning: the paper rolls around
a cylinder, its pale back face folds over the unturned part, and `to` waits
underneath with a soft shadow at the fold.

- **Corner** — which corner lifts first.
- **Radius** — the roll's radius, as a fraction of the frame height.
- **Ease** — timing.

## Use it when

- Photo albums, storybooks, recipe and portfolio edits: anything that is
  a sequence of pages.
- Chapter breaks in a slow, deliberate piece where the audience should
  see the turn.
- Children's content, where the literal metaphor is the charm.

## Avoid when

- Almost everything else: it is the most dated transition in the box and
  reads as a slideshow default on live action.
- Fast cuts; under a second the roll is a smear.
- Frames with important action in the lifting corner.
