# Reactive Grade

A grade that listens: saturation, contrast and temperature as usual, plus
signals that push the picture on the beat. An audio follower on **bass**
adds saturation; three notes play it like an instrument — C1 saturates,
D1 flashes, E1 punches in.

- **Saturation / Contrast / Temperature** — the static grade.
- **Bass → Saturation**, **Note → Saturation**, **Flash Amount**, **Punch Amount** — how far each signal moves the picture.
- Signals: **bass** (cc 1), **sat** (C1 velocity), **flash** (D1 gate), **punch** (E1 velocity).

## Use it when

- Music video and live work, where the picture should breathe with the bass.
- Performed hits: a flash on D1, a punch on E1, played against the cut.
- A saturation pump on a chorus, with the static grade left honest.

## Avoid when

- No signals routed. Then it is a grade, and Color Adjustments is the
  editable one.
- Skin in frame on the pump. Saturation moving on a face reads as a fault.
- Drama or documentary, and any audience where flash frames are a risk.
