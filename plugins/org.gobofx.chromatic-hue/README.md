# Chromatic Hue

A keyboard where every key is a hue. The key (C1–B1) picks the rotation,
**Degrees Per Key** apart; velocity sets how much of it is applied; the
pitch wheel fine-tunes within **Bend Range** and aftertouch saturates.
With **Hold** on, the last hue stays after the key is released.

- Signals: **key** (pitch, latched), **held** (velocity), **bend**, **pressure**.

## Use it when

- Live visuals where a keyboard player colours the picture by hand.
- Colour hits on a cue in a music video: one key per section, **Hold** on,
  so the hue stays until the next key.
- Performed VJ sets where the picture is the instrument.

## Avoid when

- Anything played back without the performance input. With no signal the
  picture sits on one hue or none; nothing happens.
- Skin in frame. A rotated hue turns faces green or purple in a few
  degrees. Key the background and leave the people alone.
- A fixed hue shift you set once. Use Hue/Saturation. A grade that follows
  the audio rather than the keys is Reactive Grade.
