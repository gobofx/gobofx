# Chromatic Hue

A keyboard where every key is a hue. The key (C1–B1) picks the rotation,
**Degrees Per Key** apart; velocity sets how much of it is applied; the
pitch wheel fine-tunes within **Bend Range** and aftertouch saturates.
With **Hold** on, the last hue stays after the key is released.

- Signals: **key** (pitch, latched), **held** (velocity), **bend**, **pressure**.
