# Plasma

The classic sum-of-sines plasma, mapped onto a rotating hue palette. Opaque;
stack an effect over it or use it as a background.

- **Scale** — waves across the frame; **Speed** — cycles per second.
- **Hue** — rotates the palette; **Saturation** — 0 is grey.
- **Complexity** — stretches the inner terms for busier patterns.
