# Doorway

`from` swings open as two doors hinged at the frame edges, revealing `to`
settling in from a slight zoom.

- **Perspective** — foreshortening of the doors.
- **Zoom** — how far `to` starts zoomed in.
- **Ease** — timing.

## Use it when

- A reveal: a product, a location, a chapter title. The doors open on
  the thing itself.
- Broadcast openers and kids' content, where the move is part of the fun.
- Opening on a wide, so the zoom-in on `to` settles into a composition.

## Avoid when

- Drama or documentary. It is a show device, not a story one.
- `to` has a face dead centre. The settling zoom pushes through it.
- More than once per project. One doorway is a motif; two is a template.
  Otherwise, hard cut.
