# Random Tile

The picture cut into a grid and the tiles shuffled: every piece appears
exactly once, somewhere else, and with Flip on some are mirrored too. A
seed is a fixed arrangement, so the shuffle holds still on a clip and
changes only when you ask. 1×1 without Flip is a no-op.

- **Columns / Rows** — the grid (1 to 12 each).
- **Seed** — which arrangement, 0 to 99; step it to reshuffle.
- **Flip** — also mirror tiles at random, horizontally and vertically.

## Use it when

- A puzzle, a glitch or a "scrambled" beat that resolves: keyframe nothing,
  cut to the unshuffled shot.
- Breaking a repeating texture's pattern before tiling it, so the repeats
  stop lining up.
- Abstract backgrounds from a graphic or a colour field, where the cut-up
  reads as collage.

## Avoid when

- The viewer must still read the picture; faces and type become a jigsaw.
- A moving shuffle is wanted: changing the seed cuts to a new arrangement,
  it does not animate between them.
- A regular repeat is the aim: Tile.
