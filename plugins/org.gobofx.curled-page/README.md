# Page Curl

A static page peel: the picture lifts from one corner and rolls around a
cylinder towards the opposite corner, its pale back face folding over the
part still flat, with a soft shadow at the fold. Where the page has gone the
frame is transparent, so whatever is underneath shows. At Amount 0 the page
lies flat and the picture passes through unchanged.

- **Corner** — which corner lifts.
- **Amount** — how far the curl has come: 0 flat, 1 the page gone.
- **Radius** — the roll's radius, as a fraction of the frame height.
- **Back Face** — the brightness of the paper's back: 1 white, 0 black.

## Use it when

- A held, partly turned page over the next one: a photo album, a storybook,
  a recipe card, with the layer below carrying the next image.
- Keyframing a turn that stops, hesitates and goes back, which a transition
  cannot do.
- A sticker, a label or a poster corner peeling on a product shot, small
  radius, low amount.

## Avoid when

- A straight cut from one page to the next: use the Page Curl transition,
  which handles both clips and the shadow between them.
- Live action that is not a book or a print; it is the most dated warp in
  the box and reads as a slideshow.
- Action in the lifting corner.
