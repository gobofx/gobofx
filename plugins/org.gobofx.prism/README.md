# Prism

A chromatic split: red is dragged one way along an angle, blue the other,
green smeared between them, each over a soft stretch rather than a hard
shift. Edges grow rainbow fringes and the picture goes slightly soft along
that axis. Amount 0 is a no-op.

- **Amount** — how far the channels pull apart, in pixels (up to 64).
- **Angle** — direction of the split in degrees; 0 is horizontal, 90 vertical.

## Use it when

- A glitch, VHS or "broken signal" beat: a few pixels on a cut, more on a
  hit.
- A dream or impact frame where the world should come apart for a moment,
  animated from 0 and back.
- A title that wants a cheap-lens, music-video edge.

## Avoid when

- You are after real lens aberration: that fringes radially from the
  centre, not along one axis; use Chromatic Hue.
- Anything with text to read or a face to look at for long: the fringe is a
  fault, and the eye treats it as one.
- Clean motion blur is the goal: Directional Blur keeps the colours
  together.
