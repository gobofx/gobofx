# Grid

Evenly spaced lines, transparent between them by default so it overlays a clip.

- **Line / Background** — colours, with alpha.
- **Columns / Rows** — cells across and down (Rows 0 = square cells).
- **Line Width** — in pixels. **Center** — a line passes through the handle.

## Use it when

- Layout and alignment while cutting a split screen or a multi-up.
- A graphic bed in a HUD, map or tech sequence, with **Background**
  transparent.
- A composition overlay during the edit, switched off for delivery.

## Avoid when

- Left on in a delivery by accident. Check the final export.
- Thin lines over camera moves. They strobe and alias.
- You want hexagons. Use Hex Grid.
