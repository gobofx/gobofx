# Push

`to` slides in and pushes `from` out the other side; the two move as one.

- **Direction** — the way the pair travels.
- **Ease** — timing.

## Use it when

- Slideshows and stills, where both pictures are flat and the move is clean.
- Presentation and interface pacing: a card goes, the next one arrives.
- A location montage, every push in the same direction.

## Avoid when

- Narrative. The frame is a frame, not a conveyor.
- Mixed directions in one sequence. Pick one and keep it.
- Two shots with camera movement. The push and the pan fight. For a layer
  arriving over a hold, use Slide.
