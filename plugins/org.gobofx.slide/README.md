# Slide

`to` slides in over `from`, which stays put underneath.

- **Direction** — where `to` enters from.
- **Ease** — timing.

## Use it when

- A layer entering over a hold: a card, a photo, a caption plate.
- A picture-in-picture arriving.
- Presentation pacing, where `from` stays as the ground.

## Avoid when

- Narrative. Hard cut.
- `from` has to leave too. That is Push.
- Mixed directions in one sequence. Pick one.
