# Old Film

A worn print: hairline scratches, dust specks, brightness flicker, gate
weave, grain, a sepia tone and a vignette. Each control is independent, so
you can keep only the parts you want.

- **Scratches**, **Dust**, **Flicker**, **Jitter**, **Grain**, **Sepia**, **Vignette**.

## Use it when

- An archival or flashback insert that must read as old in one frame.
- A found-footage or home-movie sequence.
- A gag. Turn **Sepia** down and keep the weave and the dust.

## Avoid when

- The whole project. It is dated by design; one stylisation per project, and
  this is a loud one.
- Stacking it with Film Grain or Vignette. Use the sliders here; they already
  have both.
- Footage that is genuinely archival. Add nothing. And **Sepia** on living
  skin makes everyone look embalmed.
