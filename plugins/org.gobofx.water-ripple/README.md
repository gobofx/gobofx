# Ripple

Concentric water ripples across the whole frame, running outward from a
point with time. Unlike Droplet it has no radius and needs no keyframes. At
Amplitude 0 the picture passes through unchanged. Pixels pulled from outside
the frame repeat the edge.

- **Center** — where the rings come from.
- **Frequency** — rings per frame height.
- **Amplitude** — displacement in frame heights; 0 is a no-op.
- **Speed** — rings per second outward; negative runs them inward, 0 freezes them.

## Use it when

- A reflection in water, a puddle or a pool under a title or a still.
- A dream, a memory or a flashback cue, kept slow and small.
- A looping background for a lyric or a lower third.

## Avoid when

- The disturbance is local or needs to start and stop: use Droplet and
  keyframe its Phase.
- Fine text or thin lines are in frame; a whole-frame ripple makes them
  shimmer unreadably.
- Footage already contains real water; two ripple patterns never agree.
