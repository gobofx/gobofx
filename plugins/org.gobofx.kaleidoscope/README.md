# Kaleidoscope

Radial mirror segments around a point, played from a keyboard: the key
(notes C1–B1) picks the segment count between **Min** and **Max Segments**,
holding a key opens the fold, the mod wheel spins it and the pitch wheel
zooms. Without any signal the picture passes through unchanged.

- **Min / Max Segments** — the range the keys select from.
- **Zoom** — base zoom; **Bend Zoom** — how far the pitch wheel zooms.
- **Center** — the mirror point.
- Signals: **key** (pitch, latched), **held** (gate), **spin** (cc 1), **bend**.

## Use it when

- Live visuals and VJ sets, where the keys choose the fold on the beat.
- A psychedelic section of a music video played in by hand.
- A dream passage driven by a single held key, with the mod wheel adding
  the slow spin.

## Avoid when

- Playback with no signal routed. The picture passes through and nothing
  happens.
- Faces at low **Segments**. A face folded in four is a flower of eyes.
- More than one stylisation per project. For a static mirror or repeat,
  Mirror and Tile need no performer.
