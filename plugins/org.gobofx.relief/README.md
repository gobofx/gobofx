# Relief

The classic grey emboss. Brightness is read as height and lit from one
side: slopes facing the light go white, the others black, everything else
mid grey. Colour is discarded; only the shape of the tones remains.
**Amount** 0 returns the source untouched.

- **Light Angle** — in degrees; 0 lights from the right, 90 from above, 135 from the upper left.
- **Height** — in pixels; how tall the relief is. 1–2 px traces edges, 6–8 px gives broad, soft hills.
- **Amount** — 0 is the source, 1 is the full grey relief; in between keeps a ghost of the colour.

## Use it when

- A stamped metal, coin or plaster look for a title, a seal or a logo on a flat backing.
- Making a bump or texture plate from a picture to overlay on another layer in a soft-light blend.
- A deliberately dated, computer-graphics moment, used knowingly.

## Avoid when

- You want the picture to keep its colour: use Indent, which shades the colour instead of replacing it.
- Portraits and faces; the result is an eerie grey mask.
- Noisy or compressed footage: every speck becomes a bump. Blur first or keep **Height** at 1.
