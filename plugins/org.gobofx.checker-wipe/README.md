# Checker Wipe

The frame becomes a checkerboard; one set of cells changes to `to`, then
the other.

- **Columns / Rows** — the board (Rows 0 = square cells).
- **Spread** — time between the two sets; **Jitter** — randomises each cell.
- **Softness** — hard flips or per-cell fades; **Ease** — timing.
