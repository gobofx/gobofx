# Checker Wipe

The frame becomes a checkerboard; one set of cells changes to `to`, then
the other.

- **Columns / Rows** — the board (Rows 0 = square cells).
- **Spread** — time between the two sets; **Jitter** — randomises each cell.
- **Softness** — hard flips or per-cell fades; **Ease** — timing.

## Use it when

- Title card to picture in a quiz, game or kids' piece, where the board is
  the right register.
- Graphic and stop-motion sequences cut on a beat. Set **Softness** to 0 for
  hard flips.
- A pixel-reveal in a retro or tech piece, with **Jitter** up and small cells.

## Avoid when

- Faces. Cells carving through a face are brutal; a hard cut is kinder.
- Narrative of any weight. It is a graphic device, not a story one.
- You want the tiles to turn in 3D. That is Mosaic.
