# Checkerboard

Two colours in a grid, with rotation and a movable origin.

- **Color A / Color B** — the two cells, with alpha.
- **Columns** — cells across the width; **Rows** — down the height, or 0 for
  square cells derived from Columns.
- **Rotation** and **Center** — turn the grid about the handle.

## Use it when

- A transparency check under a composite. Alpha mistakes show instantly over
  a checker that nothing else looks like.
- A pattern bed behind a cut-out graphic or a title, with one colour's alpha
  dropped so the picture shows through.
- Scale and alignment checks when laying out a split screen.

## Avoid when

- As a picture on its own. It is a bed or a test card, never the shot.
- Under text at the default contrast. Pull **Color B** towards Color A or the
  type disappears into the cells.
- You want angled bands, not cells. Use Stripes.
