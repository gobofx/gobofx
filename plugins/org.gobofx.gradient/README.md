# Gradient

A two-colour ramp: linear, radial or diamond. Every style passes through
**Center**, so moving the handle moves the whole gradient.

- **Style** — linear (a straight ramp turned by **Angle**), radial (rings
  around Center) or diamond.
- **Color A / Color B** — the ends of the ramp; alpha is respected, so a
  transparent Color B makes a soft vignette-like layer.
- **Span** — ramp length in frame heights; smaller is a harder edge.
- **Midpoint** — where the two colours meet; 0.5 is linear.
- **Repeat** — mirror-repeat the ramp instead of clamping at the ends.
