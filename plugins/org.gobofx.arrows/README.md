# Arrows

A row of chevrons, drawn as a coloured band, sweeps across the frame with
`to` following right behind it. The arrows point the way the wipe travels.

- **Direction** — which way the arrows travel.
- **Count** — chevrons across the frame (1–16).
- **Depth** — how far each tip leads its notches; 0 is a straight edge.
- **Band** — width of the coloured band; 0 leaves only the chevron edge.
- **Color** — the band's fill (alpha respected).
- **Softness** — feather of the band's edges.
- **Ease** — timing.

## Use it when

- Sports, news and explainer packages where the graphic language is bold.
- Direction means something: forward in time, the next stop, the next item.
- Brand work; match the band colour to the identity.

## Avoid when

- Drama, lifestyle or anything that should feel unforced: a plain Wipe is calmer.
- Fine text sits on the cut; the chevrons slice through it.
- You want a band without the teeth: Band Sweep carries a plain graphic band.
