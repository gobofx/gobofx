# Directional Blur

Motion blur along a single direction.

- **Angle** — the streak direction. **Length** — the streak, in pixels.

## Use it when

- Faking motion blur on a graphic or a cut-out that moves without it.
- A speed streak on a whip pan or a hit, keyed to the direction of travel.
- Smoothing a strobing texture along one axis in a backing layer.

## Avoid when

- A locked-off shot of a person. It reads as a render error, not motion.
- Streaks that should come from a point. Use Zoom Blur.
- General softening. Use Gaussian Blur.
