# Spin

`from` spins and shrinks into the distance, revealing `to` behind it.

- **Turns** — rotations over the transition; **Zoom** — how far it shrinks.
- **Center** — the pivot.
- **Ease** — timing.

## Use it when

- Broadcast promos, sports and game shows.
- A logo spinning away to reveal the picture.
- A comedic exit.

## Avoid when

- Narrative. Hard cut.
- Two live-action shots. The spin reveals the backing around the frame.
- More than once per project. For the quiet version, use Scale.
