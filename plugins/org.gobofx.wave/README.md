# Wave

Sine-wave displacement that ripples through the picture over time.

- **Amplitude**, **Wavelength** (in frame heights), **Direction**.
- **Phase** — offset; **Speed** — cycles per second (0 freezes it).

## Use it when

- An underwater or heat-haze beat.
- A dream, a fever, a signal going wrong.
- A glitched title; set **Direction** to horizontal and **Amplitude** small.

## Avoid when

- Faces. The sine runs through them.
- The whole project. One stylisation per project.
- A ripple from a point. Use the Ripple distort effect. A frozen wave
  (**Speed** 0) on a locked shot reads as a lens fault.
